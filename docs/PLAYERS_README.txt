PHANTOM: The Umbral Descent
===========================

HOW TO PLAY
  1. Unzip this whole folder somewhere (do not run it from inside the ZIP).
  2. Double-click PhantomDescent.exe.
     Java is included in the "jre" folder - nothing else to install.
  3. If Windows shows "Windows protected your PC", click "More info" then "Run anyway"
     (the game is not code-signed).

CONTROLS
  Move .............. A / D  or  arrow keys
  Jump .............. Space  (hold for higher)
  Strike ............ J      (hold W or S to aim up / down)
  Interact / rest ... W      (benches, NPCs, shrines)
  Focus (heal) ...... hold F
  Dash .............. K or Shift   (after the first boss)
  Light Bolt ........ L            (after the Root Shrine)
  Map ............... Tab
  Pause ............. Esc

Saves are stored in C:\Users\<you>\.phantom-descent\
